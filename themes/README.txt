PANDUAN MENGGANTI PNG KARAKTER & BACKGROUND SECARA MANUAL

Setiap tema karakter memiliki folder sendiri di dalam folder `public/themes/`:
- public/themes/spongebob/
- public/themes/woody/
- public/themes/pikachu/
- public/themes/doraemon/

Di dalam masing-masing folder terdapat 2 file PNG:
1. character.png   -> Gambar karakter transparan (disarankan PNG transparan, rasio sekitar 480x350 px).
2. background.png  -> Gambar latar header banner (disarankan ukuran lebar sekitar 1600x180 px).

Cara mengganti secara manual via file:
- Ganti saja file `character.png` atau `background.png` di folder tema yang diinginkan dengan file PNG milik Anda sendiri (gunakan nama file yang sama persis: `character.png` dan `background.png`).

Cara mengganti langsung dari aplikasi web:
- Klik tombol "Tema" -> pilih "Upload PNG Karakter / Background Manual", lalu pilih file PNG dari komputer atau HP Anda.
